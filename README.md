# TM Proxy

**Made by Reza (R.S)**

پیدا کردن و تست پروکسی‌های سالم تلگرام (MTProto) — مخصوص اینترنت ایران.

## امکانات
- جمع‌آوری پروکسی از بیش از ۷۰ منبع (گیت‌هاب، سایت‌ها، کانال‌های تلگرام)
- تست واقعی FakeTLS handshake؛ فقط پروکسی‌هایی که واقعاً کار می‌کنند «تأییدشده ✓» می‌شوند
- اتصال مستقیم به تلگرام با یک لمس
- کپی و ذخیرهٔ لیست سالم‌ها، QR برای اشتراک بدون اینترنت
- تست IP، اپراتور، پینگ و سرعت اینترنت
- حالت نت ملی، اینترنت ضعیف و اینترنت خوب
- علاقه‌مندی‌ها و سابقهٔ پایداری هر پروکسی برای هر اپراتور

## نصب
1. `RS-Proxy.apk` را دانلود کنید
2. اجازهٔ نصب از منبع ناشناس را بدهید
3. اپ **TM Proxy** را باز کنید و «شروع اسکن» را بزنید

## نکته
پروکسی‌های کلاسیک و dd در ایران معمولاً فیلترند؛ TM Proxy به‌صورت پیش‌فرض فقط FakeTLS را تست می‌کند.

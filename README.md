## English

Find and test working Telegram (MTProto) proxies — built for Iran's internet.

### Features
- Collects proxies from 70+ sources (GitHub, websites, Telegram channels)
- Real FakeTLS handshake test — only proxies that truly work are marked **Verified ✓**
- One-tap connect to Telegram
- Copy & save the healthy list, QR code for offline sharing
- IP, operator, ping and internet speed check
- Modes for national internet, weak internet and good internet
- Favorites and per-operator stability history for each proxy

### Download
Get the latest version from **Releases**: `TM-Proxy.apk`
(Android 8.0 or newer)

### Install
1. Download `TM-Proxy.apk`
2. Allow installing from unknown sources
3. Open **TM Proxy** and tap "Start scan"

### Note
Classic and dd proxies are usually blocked in Iran; TM Proxy tests FakeTLS only by default.

## فارسی

پیدا کردن و تست پروکسی‌های سالم تلگرام (MTProto) — مخصوص اینترنت ایران.

### امکانات
- جمع‌آوری پروکسی از بیش از ۷۰ منبع (گیت‌هاب، سایت‌ها، کانال‌های تلگرام)
- تست واقعی FakeTLS handshake؛ فقط پروکسی‌هایی که واقعاً کار می‌کنند «تأییدشده ✓» می‌شوند
- اتصال مستقیم به تلگرام با یک لمس
- کپی و ذخیرهٔ لیست سالم‌ها، QR برای اشتراک بدون اینترنت
- تست IP، اپراتور، پینگ و سرعت اینترنت
- حالت نت ملی، اینترنت ضعیف و اینترنت خوب
- علاقه‌مندی‌ها و سابقهٔ پایداری هر پروکسی برای هر اپراتور

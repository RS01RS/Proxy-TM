# 📨 TM Proxy — find, test & use Telegram proxies

An Android app to find, **really test** and use Telegram proxies — built for heavily restricted networks, from the open internet to a national intranet. No servers ship in the app.

## ⬇️ Download
Get the latest build from **Releases**:
- `TM-Proxy-universal.apk` — **if you don't know your phone, get this one** (works on all phones)
- `TM-Proxy-arm64.apk` — newer 64-bit phones, smaller
- `TM-Proxy-arm32.apk` — older 32-bit phones

Android 8+ · 64-bit phones for all features.

## 🔎 Finding & testing proxies
- Free proxies from **many public sources**, with mirrors and **secure DNS (DoH)** when a path is blocked.
- Proxy types: **MTProto** (FakeTLS, dd, classic), **WEB** and **SOCKS5**; a "FakeTLS only" option (recommended; classic and dd are usually blocked).
- **Real testing** of each proxy (not just ping): it actually connects to Telegram; results in three groups **working / suspect / down**.
- **Separate per-operator stability history**.

## 📶 Operator & network info
**IP, operator** (auto-detected or chosen), **location, ISP, ping abroad/domestic, download speed**, with separate history and settings per operator.

## 🎛 Filter & sort
Filter by **type, port 443, resistant, fresh, domestic only** · **flags and location** · sort (best, lowest ping, most stable, most resistant).

## ⭐ Favourites
Star good proxies; they are **re-tested periodically** so a working proxy is always ready.

## 🚀 Using
**One-tap connect to Telegram**, and an "after a scan, auto-connect to the best proxy" option.

## 🛰 National net (when international internet is cut)
- **Run Telegram straight through your own DNS tunnel** — when even DNS works but the rest of the internet doesn't, Telegram is carried inside DNS queries.
- **DNS tunnel with several engines:** MasterDNS, StormDNS, CottenDNS (and CottenMax), Soar. You enter **your own server profile** (no servers ship in the app), keep several, pick one.
- **Resolvers:** a large built-in bank + a healthy-resolver finder + **discovery of new resolvers** from domestic IP ranges; verified before use.
- **thefeed:** read Telegram channels over DNS, show messages, fetch images and files, **QR reading**.
- **Domestic sources:** get proxies from domestic sources for shutdown days.

## 📥 Manual import
Manual proxy import (copy from a channel, Bluetooth…) and **auto-detect from the clipboard**.

## 📤 Sharing & export
**TXT/CSV** export, sharing, and **send the app itself offline**.

## ⚙ Scan settings
Address and count, ping, concurrency, test timeout, and **auto-scan**.

## 🎨 Other
Five languages · dark/light/auto themes · full logs.

## 🔒 Privacy
The app ships no servers, domains or keys from the author; you enter profiles yourself and they stay only on your phone. No user data is ever sent anywhere.

## 🔒 Source
The source code is private and not published.

## 📜 Licenses
Built with open-source software; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

# 📨 TM Proxy — поиск, проверка и использование прокси Telegram

Приложение для Android, которое находит, **реально проверяет** и использует прокси Telegram; создано для сильно ограниченных сетей — от свободного интернета до закрытой национальной сети. В приложении нет серверов.

- Бесплатные прокси из **многих открытых источников**, с зеркалами и **защищённым DNS (DoH)**, когда путь заблокирован.
- Типы: **MTProto** (FakeTLS, dd, классический), **WEB** и **SOCKS5**; опция «только FakeTLS» (рекомендуется; классический и dd обычно блокируются).
